# مجلّد الترحيلات — OrbitX

هذا المجلد هو **المصدر الوحيد** لكل تغيير على قاعدة البيانات، بأسلوب "ملف واحد مؤرّخ لكل تغيير" (نفس منهجية المشاريع الاحترافية على Supabase).

## القاعدة الذهبية
1. كل تغيير على القاعدة = ملف جديد باسم مؤرّخ مثل `20260908000000_اسم_التغيير.sql`.
2. الملفات تُطبَّق **بالترتيب التصاعدي** مرة واحدة فقط (SQL Editor في داشبورد Supabase).
3. **أي كتابة حساسة** (نقاط، عملات، مكافآت، مشتريات) تمر عبر دالة `SECURITY DEFINER` — أبداً بشكل مباشر على الصفوف.
4. الكود يخاطب القاعدة عبر الدوال والـ REST فقط — لا تعديل صف مباشر من الواجهة.

## الملفات الموجودة

| `20260816000000_fleet_handover.sql` | نقل تسليم الأسطول للمالك الجديد | **مقدّم للتطبيق** |
| `20260905000000_baseline_documents_schema.sql` | البنية الأساسية (جدول documents + admins + دوال XP والأمان) | **يحتوي إعفاء صناديق الوقت** |
| `20260905000001_hardening.sql` | تحصين ضد الغش وسياسات سجلات الأخطاء | **مقدّم للتطبيق** |

| `20260909000000_relational_complete.sql` | **ملف نهج "ب" الشامل**: الجداول العلائقية الكاملة + كل قواعد الأمان والـ RPC بدفعة واحدة | **جاهز للتطبيق بعد توفّر DDL** |

## ملف نهج "ب" — `20260909000000_relational_complete.sql`
- يستبدل نموذج `documents` (JSONB بخزان واحد) بنظام جداول علائقية حقيقي: مستخدم، ملف، أسطول، محطة، رسالة، نزال، نقاش، رد، جدول، إعلام، صديق، معرض، اقتراح، تذكرة دعم، خطأ، تنبيه أدمن، تحديث تطبيق، إعلام عام، نصيحة، إشارة توعية، نظام، اشتراك إشعار.
- **كل القواعد في الملف نفسه**: قفل الرصيد (لا تعديل مباشر لـ xp/level/role)، تسليم قيادة الأسطول التلقائي، الـ RLS الكاملة، وأخطر دوال الأمان (grant_xp ورفيقاتها) بكل كوابح منع الغش وإعفاء صناديق الوقت.
- يمكن تشغيله بأمان أكثر من مرة (يعيد تعريف كل شي). أبسط طريقة: الصق الملف كاملاً في SQL Editor واضغط Run.

## كيف أطبّق تغييراً؟
1. أعدّ لك ملفاً مؤرّخاً جديداً في هذا المجلد.
2. تنسخ محتواه في **SQL Editor** بمشروع OrbitX على Supabase وتضغط **Run**.

## الوضع الحالي (أيلول 2026)
- القاعدة الحيّة تُقرأ/تكتب بنجاح بحساب الخدمة (service_role).
- **الأهم: لا توفرت بعد صلاحية DDL** (إنشاء جداول/دوال/سياسات) — وهذه تفتح الباب عندما نحصل على Connection String أو Access Token بحساب مالك المشروع.
