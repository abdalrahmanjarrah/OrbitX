## 📖 الفكرة العامة

لعبة زراعة على Roblox **مربوطة بموقع OrbitX**. المستخدم يدرس بالموقع → نباتاته تكبر باللعبة. لو توقف عن الدراسة → النباتات تبدأ تجف.ắng الناس تزور مزارع بعض وتنافس.

---

## 🎮 نظام اللعب

### 🌿 النباتات

| الصنف | الوصف | الحد الأعلى | السعر بالمتجر |
|-------|-------|------------|--------------|
| نبات عادي | يكبر بعد 2 ساعة تركيز | Lv.10 | 100 XP |
| نبات متوسط | أجمل، أسرع نمو | Lv.15 | 500 XP |
| نبات نادر | يلمع، تأثيرات خاصة | Lv.20 | 2,000 XP |
| نبات أسطوري | نادر جداً، حركات خاصة | Lv.25 | 10,000 XP |

#### آليات النمو
- **درس =$ النبات يكبر** — كل ساعة تركيز = نقطة نمو واحدة
- **ما درست = النبات يجف** — يخسر level واحد كل يوم بدون دراسة
- **النبات ما يموت نهائياً** — يضل Lv.1 بس لو توقفت كتير
- **كل نبات له:**
  - شكل بصري (3D model)
  - لون حسب المستوى (Lv.1 أخضر → Lv.25 ذهبي متوهج)
  - تأثيرات particles حسب الندرة

### 🏡 المزرعة

- **12 خلية × 8 صفوف = 96 خلية زراعة** لكل مستخدم
- **鲴性 متاحة مع الوقت** — كل level تفتح خلايا جديدة
- **.form زراعة متعددة** — بعض النباتات تحتاج مساحة أكبر
- **الديكور** يزيد من **zen value** المزرعة (تأثير بصري)

### 🛒 المتجر

#### الأقسام:
1. **نباتات** — 20+ صنف (عادي ← أسطوري)
2. **تربة وerrals** — تغيير شكل الأرض
3. **حيوانات** — طيور، حشرات، عناصر حية تتحرك
4. **ديكور** — مصابيح، جسور، نوافير
5. **مباني** — صالة، مستودح، برج مراقبة
6. **أدوات** — سطل ماء، سماد، محراث

#### العملات:
- **XP** — العملة الأساسية، تأتي من الدراسة بالـ OrbitX
- **Star Seeds** — عملة نادرة، تأتي من الإنجازات الأسبوعية

### 👥 الزيارة الاجتماعية

- **زيارة مزارع الناس** — تضغط على اسمهم وتروح مزرعتهم
- **تشوف شكل مزرعتهم** — النباتات، الديكور، الحيوانات
- **تعطي تقييم** — like / wow
- **تشوف leaderboard** — مين عنده أكبر مزرعة

## 🔗 الربط التقني

### المعمارية

```
┌──────────────┐     HTTP API     ┌──────────────┐
│   Roblox     │ ←──────────────→ │  OrbitX API  │
│   (Game)     │                  │  (Server)    │
└──────────────┘                  └──────────────┘
                                        ↕
                                  ┌──────────────┐
                                  │  Supabase    │
                                  │  (Database)  │
                                  └──────────────┘
```

### كيف يشتغل

1. **ربط الحسابات:**
   - المستخدم يفتح صفحة ربط بالـ OrbitX
   - يضغط "ربط حساب Roblox"
   - يفتح رابط Roblox OAuth
   - الحسابات تتربط (Roblox userId ↔ OrbitX uid)

2. **مزامنة البيانات:**
   - كل **5 دقايق**، اللعبة ترسل HTTP Request للـ API
   - الـ API يرجع **ساعات الدراسة** من آخر 24 ساعة
   - اللعبة تحوّل الساعات → **نمو النباتات**

3. **تحديث يومي:**
   - كل **يوم**، الـ API ينشئ webhook للعبة
   - يبلّغ عن التغييرات (植物 levels, new XP, etc.)

### الأمان

- **API Key** لكل Roblox game (مخبّية بالـ server)
- **Rate limiting** — حد أقصى 100 طلب/دقيقة لكل مستخدم
- **HMAC signature** لكل request
- **No secrets in client code** — كل شي بالـ ServerScriptService

### نقاط النهاية (API Endpoints)

| Method | Endpoint | الوصف |
|--------|----------|-------|
| `GET` | `/api/orbitx/focus-hours?userId={id}` | ساعات الدراسة |
| `GET` | `/api/orbitx/xp?userId={id}` | XP الحالي |
| `POST` | `/api/orbitx/sync` | مزامنة بيانات اللعب |
| `POST` | `/api/orbitx/link` | ربط حساب |
| `GET` | `/api/orbitx/farm?userId={id}` | بيانات المزرعة |
| `PUT` | `/api/orbitx/farm` | تحديث بيانات المزرعة |

### نموذج البيانات (Supabase)

```sql
-- جدول ربط الحسابات
CREATE TABLE roblox_links (
  orbitx_uid UUID PRIMARY KEY REFERENCES auth.users(id),
  roblox_user_id BIGINT UNIQUE NOT NULL,
  linked_at TIMESTAMPTZ DEFAULT now()
);

-- جدول بيانات المزرعة
CREATE TABLE roblox_farms (
  orbitx_uid UUID PRIMARY KEY REFERENCES auth.users(id),
  farm_data JSONB NOT NULL DEFAULT '{}',
  last_synced_at TIMESTAMPTZ DEFAULT now(),
  created_at TIMESTAMPTZ DEFAULT now()
);

-- جدول جدول المزامنة
CREATE TABLE roblox_sync_log (
  id BIGSERIAL PRIMARY KEY,
  orbitx_uid UUID REFERENCES auth.users(id),
  focus_hours DECIMAL(5,2),
  xp_earned DECIMAL(10,2),
  synced_at TIMESTAMPTZ DEFAULT now()
);
```
